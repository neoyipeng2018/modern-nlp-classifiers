One task, one path

The shape of it

Small on purpose

Rows in, one gatekeeper, numbers out, one registry row per number. There is no second code path for plain sentence sentiment, because plain sentence sentiment is a row whose target is the literal overall. 

load sources ──► map to the codebook ──► deduplicate ──► cut splits ──► freeze + hash
                                                                              │
                                      ┌───────────────────────────────────────┘
                                      ▼
                          build pair input (text, target)
                                      │
        ┌─────────────┬───────────────┼───────────────┬────────────────┐
        ▼             ▼               ▼               ▼                ▼
     majority     word lists      TF-IDF + LR    fine-tuned       gpt-5.6-sol
                                                  encoder          (cached)
        └─────────────┴───────────────┼───────────────┴────────────────┘
                                      ▼
                                  the harness
                          (guards, metrics, bootstrap, Holm)
                                      │
                          ┌───────────┴───────────┐
                          ▼                       ▼
                   runs/reports/*.json      runs/registry.jsonl

The harness is the only door. A word list, a logistic regression, a fine-tuned encoder and a frontier model all arrive at the same interface and are scored the same way. That is what makes the comparisons paired and the numbers comparable.

Built

Four winner settings must be added before the first small run. selection.cells is fpb, fiqa, finentity. selection.rule is first_or_tied_in_every_cell. selection.tie_break is mean_macro_f1, inference_cost. pipeline.first_tier is small. eval.aspect_correctness is contrast_pair_accuracy. eval.aspect_control is target_hidden. These values are decisions, so the settings hash must cover them.

One override flag, and it is hashed. --set a.b=value folds a value in before the hash is taken, so an override changes the run identity the same way an edit to settings.py does. There is no way to change a value that the hash cannot see.

Warning. The success bar and the published-number survey now live here. The plans said to write the thresholds and the survey into a config file and hash them. There is no config file, so the thresholds go into settings.py and the survey goes into Program design as a table. The rule that matters does not change: write the bar before the test split is opened, and commit it. What is lost is the sweep. A YAML file per experiment made a ladder of arms cheap, and a Python dictionary does not. Use --set for a one-value arm, and accept a longer command line.

What a row carries

The row schema

Four fields to add

Every row carries where it came from, what licence it arrived under and how its label was made. A row without provenance never enters a training set, and the loader raises rather than defaulting a missing field quietly.

Row fields. The four marked new are what the aspect task adds.
FieldTypeWhat it holds
example_idstringA hash of the source and the text. Rebuilding the data set gives the same identifiers, which is what lets split assignments be published without the text.
textstringThe sentence or headline. Segment A of the pair.
targetstringNew. The target string, copied from the text. The literal overall when the row has no target. Segment B of the pair. Never empty.
target_startint?New. Character offset of the target in the text, where the source gives one. Used only by the span-marker ablation.
target_endint?New. The other offset.
sentence_idstringNew. A hash of the text alone. All targets of one sentence share it, and it is the split key for the aspect sources.
labelstringpositive, negative or neutral.
label_sourceenumhuman, public, weak, distilled or augmented. Only human may appear in an evaluation split, and the harness enforces it.
source_datasetstringWhich set the row came from.
source_licencestringThe licence it arrived under. It travels with the row so a licence question is answerable at any point in the pipeline.
codebook_versionstringWhich version of the label rules produced this label. A codebook change makes a new data set, not an updated one.
agreement_tierstringFinancial PhraseBank only: all, 75, 66, 50. The tier breakdown reads this.
borrowed_row_idstringThe identifier the source used, so a number can be traced back.
dup_groupstringNear-duplicate cluster. A split key.
family_idstringAugmentation family. A paraphrase and its original share it. The other split key.
splitstringtrain, dev or test.

Warning. target is never empty and never null. An empty segment B makes the aspect case and the null case different shapes, and the model learns to read the shape instead of the target. validate() raises on an empty target, the same way it already raises on an empty text.

Three split keys now, not two. dup_group and family_id are enforced today. sentence_id joins them. All three mean the same thing: rows that share the key go to the same split, and CI fails the build when one straddles two.

From row to tokens

The input builder

Designed

One function turns a row into what the model reads. It has two modes and the mode is a config value, not a branch that anything else can reach.

Pair mode, the default

Segment A is row.text. Segment B is row.target. The tokenizer's own pair encoding puts the separator in and sets the segment identifiers. No new special tokens, no resized embedding matrix, and it works on every source including the ones with no offsets.

tok(row.text, row.target, truncation="only_first", max_length=cfg.max_len)

Truncation only ever cuts segment A. A truncated target is a different question, so segment B is never shortened.

Marker mode, the ablation

The target span is wrapped in the text with two added tokens, and segment B is dropped. It needs target_start and target_end, so it runs only on FinEntity and on the FiQA rows whose snippet matches a span.

… shares in [T] Nokia [/T] rose …

Adding two special tokens resizes the embedding matrix. On a 17M checkpoint that is not free. Price it in the smoke check.

The head-to-head is one run, one variable. Same rows, same seeds, same recipe, pair against markers. If markers do not win by a clear margin, the mode stays at pair and the marker path is deleted rather than kept as an option nobody uses.

Cut once, freeze, hash

Splits and hashing

Built, one key to add
  • One test split, cut from the Financial PhraseBank 50%-agreement superset. Every row keeps the strongest tier it reached. The four published subsets are read back as breakdowns of that one frozen split, because they are nested and four separate splits are impossible.
  • The aspect sources are cut on sentence_id, so every target of a sentence lands together.
  • What is committed is manifest.json, a manifest of hashes, and split_assignments.csv, which carries row identifiers and split assignments only. No text and no labels. finsent build-data rebuilds the exact splits by joining on example_id.
  • The config is hashed after resolution, so an inherited default cannot change a run's meaning without changing its identity.

Why the assignments file is the whole redistribution story. Financial PhraseBank is CC BY-NC-SA 3.0 and non-commercial. This project redistributes none of its text and none of its labels. The identifiers are hashes of the sentences, so the file is useless to anyone who does not already hold the source. That is deliberate.

What gets trained

Model and head

Designed
  • The head is a linear layer over the pooled representation, three outputs. No task-specific architecture, because a special architecture is a second variable and this project is measuring backbones.
  • Pooling is CLS or mean, decided by one run per candidate before the bench recipe locks. Encoders differ here and the default is not safe to assume.
  • Loss is cross-entropy. Class weights are off by default, because macro-F1 already treats the classes equally and a weight is a second variable.
  • Three seeds per configuration. The seed ensemble is reported as well, because the runs already exist and averaging them costs nothing.
  • Temperature scaling is one scalar fitted on the development split, after training, reported as expected calibration error.
  • Small-first validation trains a provisional small model with supervised fine-tuning. It runs through data, training, evaluation, calibration, cost, registry, report card and packaging on development-side evidence. It never opens the frozen test split.
  • Distillation starts after the large winner exists. It trains the final small candidate on the large winner's probabilities, then fine-tunes on the human rows. The final small candidate must pass the same three-cell winner rule again.

Max length comes from the data, not from a claim. The build measures the token distribution and the maximum length is set from its 99th percentile, rounded up. It is a configuration number like batch size. A new source with longer text means a re-measure and a new config hash.

The one gatekeeper

The harness

Built, interface to widen

Everything that produces labels is scored here and nowhere else. The harness refuses input rather than warning about it.

What it refuses

  • A split whose hash does not match the config.
  • Any evaluation split holding a non-human label.
  • A system that returns fewer predictions than rows.
  • An empty row set.

The interface change the aspect task needs

System.predict takes a list of texts today. It has to take a list of rows, or a list of pairs, because a target-blind system cannot answer a target-conditioned question. The word-list baselines then decide for themselves whether to read the target, and the report records which ones did. 

class System(Protocol):
    name: str
    reads_target: bool                       # new. Recorded in the report
    def predict(self, rows: list[Row]) -> list[str]: ...

reads_target = False is allowed and it is informative. The matched target-hidden control uses the same trained checkpoint and the same texts. It replaces segment B with overall. The report compares its contrast-pair accuracy with the normal prediction through a paired interval. 

def hide_target(row: Row) -> Row:
    return replace(row, target="overall", target_start=None, target_end=None)

One interface each

Baseline interfaces

Four built
The baselines, and whether each reads the target
BaselineFits onReads targetState

The word lists fit nothing anywhere. The rule is the sign of positive hits minus negative hits, and a tie is neutral. Read them beside their abstention rate: Loughran-McDonald is silent on 65% of development rows and Henry on 66%, and every silent row is called neutral. Most of their "neutral" is the absence of a decision.

lexicon-window is the honest aspect floor. An aspect model must beat a word list that counts hits near the target, not just one that counts hits anywhere. It is cheap, it needs offsets, and without it the aspect claim has no floor under it.

The API comparison

The frontier baseline

Pinned, not built

gpt-5.6-sol at medium reasoning effort. It is a system in the harness like any other, it is scored against human labels, and it can lose.

The pin, in full
FieldValue
modelgpt-5.6-sol. One model, one version. Not a router and not a fallback chain.
effortmedium. Part of the pin, not a tuning knob, because it changes both the answers and the bill.
prompt_versionTwo prompts, both published: zero-shot and few-shot. Few-shot examples come from train only.
cacheEvery response, with its input tokens, output tokens, reasoning tokens and date. The cache is published, so the comparison survives the model being retired.
verified_atThe identifier resolves on a live call before any run, and the call is recorded. A wrong model string that silently falls back is the failure this field exists to catch.

Warning. Reasoning tokens are billed and they are counted. Leaving them out of the cost comparison flatters the ratio by exactly the amount the reasoning setting costs. Count real token usage at recorded prices, over identical rows.

Warning. It writes no labels. In the earlier plan a frontier model wrote the test key and the headline was agreement with it. That is deleted. Here the human labels are the key and this is a contestant.

No row, no number

The registry

Built

One append-only JSONL file. Every run that happened gets a row, including the ones that failed. A number that has no row does not go in the write-up.

  • A row without a hypothesis is refused. The hypothesis is written before the run, not after the number.
  • An unknown evidence grade is refused.
  • test_hash is empty until the frozen split is opened, which happens once, at the end.

Enforced, not requested

Rules the code enforces

CI checks these
  1. The harness refuses a split whose hash does not match the config.
  2. The harness refuses any evaluation split holding a non-human label.
  3. The harness refuses a system that returns fewer predictions than rows.
  4. A near-duplicate group never straddles two splits.
  5. A paraphrase and its original never straddle two splits.
  6. All targets of one sentence never straddle two splits. New with the aspect task.
  7. A generated row that is a near-duplicate of a test row fails the build. New with Track D.
  8. A registry row without a hypothesis is refused.
  9. An unknown evidence grade is refused.
  10. A row with an empty target, text, source, licence or codebook version is refused.

The test suite needs no network and no GPU. The data invariant checks run on synthetic rows, which is what makes them runnable in CI at all. The dataset loaders are exercised by finsent build-data, which needs network, and not by CI.
